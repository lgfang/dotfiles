* WezTerm

** Why WezTerm over iTerm2

As a Tmux + Emacs user on macOS, I don't need a built-in multiplexer, tabs, or
panes. That narrows the choice down to a few points that actually matter to me:
- Configured via a file rather than a GUI, which means it is
  - version-controllable, and
  - faster to change settings - editing a config file beats hunting through a
    maze of nested preference tabs and panes.
- Custom hyperlink rules.

** Config Initialisation
#+begin_src lua :tangle ~/.wezterm.lua
  local wezterm = require 'wezterm'
  local config = wezterm.config_builder()
#+end_src

*** Fonts

**** Font

See [[https://github.com/ryanoasis/nerd-fonts/discussions/1103][this post]] for the differences between the 3 nerd font variants (nerd font,
nerd font mono, and nerd font propo).

Some popular fonts:
- ~Liga SFMono Nerd Font~: ~brew install font-sf-mono-nerd-font-ligaturized~
- ~FiraCode Nerd Font~: ~brew install font-fira-code-nerd-font~
- ~JetBrains Mono~: builtin
- ~Cascadia Code NF~ (with ~DemiLight~ weight): ~brew install font-cascadia-code-nf~

On fallback fonts:
- ~wezterm.font_with_fallback~ takes a list: the first entry is the main font,
  the rest are consulted in order for glyphs the main font lacks.
- WezTerm ships builtin fallbacks, so setting them is optional. Normally it is
  done to deliberately mix fonts.
- ~PingFang SC~ is the macOS default Chinese font, listed here as an example of
  adding a CJK font to the fallback chain. A CJK font must always be placed
  *last*: it also covers punctuation and full-width Latin, so an earlier
  position would let ASCII/Latin glyphs fall back to it, which is usually
  undesirable.
- The other entries mirror WezTerm's own defaults, kept here as the place to
  edit for further overrides.

#+begin_src lua :tangle ~/.wezterm.lua
  config.font_size = 16
#+end_src

#+begin_src lua :tangle ~/.wezterm.lua
  local font_family = 'Cascadia Code NF'

  local fallback_fonts = {
      'JetBrains Mono',
      'Noto Color Emoji',
      'Symbols Nerd Font Mono',
      'PingFang SC',
  }

  -- Helper function to create a font object with fallback
  local function font_with_weight(weight)
      return wezterm.font_with_fallback({
              { family = font_family, weight = weight },
              table.unpack(fallback_fonts)
      })
  end

  config.font = font_with_weight('DemiLight')
#+end_src

Optionally set weights per intensity. An unavailable weight silently falls back
to the closest one.
#+begin_src lua :tangle ~/.wezterm.lua :tangle no
  local font_rules = {
      {
          -- NOTE: this intensity rule shadows config.font for ordinary text
          intensity = 'Normal',
          font = font_with_weight('Medium'),
      },
      {
          -- Increase the weight of Bold text
          intensity = 'Bold',
          font = font_with_weight('ExtraBold'),
      },
  }

  config.font_rules = font_rules
#+end_src

NOTE: to test ~bold_brightens_ansi_colors~, verify the results in a shell CLI.
Do NOT do it within Emacs, as Emacs themes may apply their own brightness
adjustments that could interfere with the results.

Use the following commands to display bold and normal text with colours:

*** COMMENT Opacity

This is interesting, but I often prefer to disable it as the background can be
distracting.

Additionally, for Emacs running in the terminal to support opacity, set its
background to "unspecified-bg" as shown below:
#+begin_src emacs-lisp
  (set-face-background 'default "unspecified-bg")
#+end_src

*** Colour theme

The remote window uses a different scheme, keyed off the tmux window
title prefix set by =set-titles-string= (see tmux.org).

#+begin_src lua :tangle ~/.wezterm.lua
  config.color_scheme = 'GruvboxDark'

  wezterm.on(
      'update-right-status',
      function(window, pane)
          local title = pane:get_title()
          if title and title:match('^ws:') then
              window:set_config_overrides({ color_scheme = 'Solarized Dark - Patched' })
          else
              window:set_config_overrides({ color_scheme = 'GruvboxDark' })
          end
  end)
#+end_src

** Bell

Terminal should ring a bell (alert) upon the ascii character BEL (~printf '\a'~).
#+begin_src lua :tangle ~/.wezterm.lua
  config.audible_bell = "SystemBeep"
  config.visual_bell = {
     fade_in_duration_ms = 75,
     fade_out_duration_ms = 75,
     target = "BackgroundColor"
  }
  config.colors = {
     visual_bell = '#202020',
  }
#+end_src

NOTE: This does not work in the Emacs TUI, as its constant redrawing obscures
the terminal emulator's visual effects. Use ~ring-bell-function~ in Emacs for a
custom effect like flashing the mode line.

** Custom hyperlinks
#+begin_src lua :tangle ~/.wezterm.lua
  -- Use the defaults as a base
  config.hyperlink_rules = wezterm.default_hyperlink_rules()
  table.insert(
     config.hyperlink_rules,
     {
        -- example: clicking on SERVER-1234 opens this mongodb sever ticket
        regex = [[\b((SERVER|server)-[0-9]+)\b]],
        format = 'https://jira.mongodb.org/browse/$1'
     }
  )
#+end_src
