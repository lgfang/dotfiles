* Sample text

- 平安喜乐 :: Chinese characters
- 👍 (\u1F44D) :: single-code-point emoji - Thumbs Up Sign
- 👍🏻 (\u1F44D \u1F3FB) :: emoji with skin tone modifier - Thumbs Up Sign +
  Emoji Modifier Fitzpatrick Type-1-2
  + The modifier character is invisible on its own and selects a skin tone
    for the preceding emoji. These two characters render as one glyph.
    However, if ~auto-composition-mode~ is disabled, they render as two
    separate characters.
- 🏖 (\u1F3D6) :: emoji with multiple presentation styles - Beach with Umbrella
  + Renders as single-width unless followed by a trailing space, which allows it
    to expand to width 2. Compare 🏖 and 🏖: the former expands into the trailing
    space; the latter stays width 1 with no space to expand into.
  + *Reason*: this character can be rendered in two styles: text or emoji. When
    standalone, default to text presentation (narrow, monochrome). However,
    WezTerm overrides this and tries to draw a wide emoji, but Emacs follows the
    standard and treats it as width 1.
  + We can append a variation selector to explicitly select presentation style.
    The selector is invisible; both characters render as one glyph (unless
    ~auto-composition-mode~ is disabled, in which case they appear separate):
    - 🏖️ (\u1F3D6 \uFE0F) :: VS16 — emoji presentation
    - 🏖︎ (\u1F3D6 \uFE0E) :: VS15 — text presentation (explicit, same as default)
- 👩‍💻 (\u01F469 \u200D \u01F4BB) :: emoji with Zero Width Joiner (ZWJ) -
  Woman + ZWJ + Personal Computer
  + The ZWJ makes 👩 and 💻 combine into one glyph (Woman Technologist). If
    ~auto-composition-mode~ is disabled, all characters appear separately.
    Two more ZWJ examples below:
    + 🤦‍♂️ (\u01F926 \u200D \u02642 \uFE0F) :: Face Palm + ZWJ + Male Sign +
      Variation Selector-16 = Man Facepalming
    + 🤦‍♀️ (\u01F926 \u200D \u02640 \uFE0F) :: Face Palm + ZWJ + Female Sign +
      Variation Selector-16 = Woman Facepalming

* Entering Unicode Characters and Emojis

** By name or code point: ~C-x 8 RET~ (~insert-char~)

Prompts for a character by Unicode name (e.g. "SMILING FACE WITH OPEN MOUTH")
or hex code point (e.g. ~1F603~ or ~#x1F603~). Tab completion is available.

#+begin_example
  C-x 8 RET 1F603 RET      →  😃
  C-x 8 RET SMILING RET    →  😃   (completes on name substring)
#+end_example

** Emoji picker: ~C-x 8 e~ (~emoji-insert~)

Available in Emacs 29+. Opens a dedicated emoji selector with categories,
recent emojis, and search. In terminal Emacs the picker may fall back to
~insert-char~ if it cannot render the grid.
